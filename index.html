Yoto CSV Generator - Help

Regular tracks

Any audio file whose name does not start with #00–#99 is a regular track. regular

Regular tracks play one after another. The Yoto knob moves forward (confirm/continue) to the next track and backward (rotate/return) to the previous one. When the last track in a folder finishes it returns to the parent menu automatically.

Example — a single album

Song 1.mp3 Song 2.mp3 Song 3.mp3

Tracks play in alphabetical order. Rotating goes back one track; confirming skips forward. No special naming needed.

Special tracks

Prefix a filename with #NN (two digits) to give it a special role. The rest of the filename is up to you (e.g. "#01 Something.mp3", "#01_intro.m4a" and "#01.aac" are all valid names). Three prefixes are recognised:

  • #00 — Intro intro — plays once, then jumps straight to the first choice.
  • #01–#98 — Choice choice — the listener rotates through these options and confirms to select one.
  • #99 — Answer / Resolution answer — plays after a choice is confirmed (e.g. the correct answer), then advances automatically.

A folder must use either all regular tracks or all special tracks — mixing the two is not allowed.

Use case — book or album collection

Put each book or album in its own sub-folder. Name the sub-folders #01 Book Title, #02 Book Title, … and add a matching choice track in the root folder with the same number. Confirming a choice dives straight into that book's tracks.

Without an intro

#01 Treasure Island.mp3 ← choose this book #02 Jungle Book.mp3 ← or this one #01/ ← tracks for Treasure Island Track 1.mp3 Track 2.mp3 #02/ ← tracks for Jungle Book Track 1.mp3 Track 2.mp3

The card starts on #01 Treasure Island. Rotate to cycle between books; confirm to start listening. Finishing the last track returns to the book-selection menu.

With an intro

#00 intro.mp3 ← "Which book would you like?" #01 Treasure Island.mp3 #02 Jungle Book.mp3 #01/ … #02/ …

The intro plays automatically when the card is inserted, then jumps to the first choice. Everything else works the same way.

Use case — quiz

A quiz question is a folder that contains a #00 question track, two or more #NN answer choices, and a #99 resolution track that reveals the correct answer.

#00 question.mp3 ← "What is the capital of France?" #01 choice A.mp3 ← "Paris" #02 choice B.mp3 ← "London" #99 answer.mp3 ← "Correct! It's Paris."

The question plays automatically. The listener rotates through the choices and confirms their answer. The #99 answer track plays.

Use case - multi-language quiz

Wrap the quiz in an outer language-selection layer. The root folder holds one choice track per language; each language folder then contains its own question.

#00 intro.mp3 ← "Choose your language" #01 choice english.mp3 ← English #02 choice french.mp3 ← Français #01 EN/ ← English question #00 question.mp3 #01 choice A.mp3 #02 choice B.mp3 #99 answer.mp3 #02 FR/ ← French question #00 question.mp3 #01 choice A.mp3 #02 choice B.mp3 #99 answer.mp3

After the intro the listener picks a language. Confirming dives into that language's question folder. When the answer plays, the quiz loops back to the language selector so the card is reusable.

Use case - extended multi-language quiz

When a language (or topic) contains many questions, nest each question in its own numbered sub-folder inside the language folder. The language folder itself stays empty (no audio files directly inside it) — it acts purely as a container that sequences its children in order.

#00 intro.mp3 #01 choice english.mp3 #02 choice french.mp3 #01 EN/ ← empty — just a container #01 question1/ ← question 1 #00 question.mp3 #01 choice A.mp3 #02 choice B.mp3 #99 answer.mp3 #02 question2/ ← question 2 #00 question.mp3 #01 choice A.mp3 #02 choice B.mp3 #99 answer.mp3 #02 FR/ ← same structure in French #01 question1/ … #02 question2/ …

After the answer to question 1 plays, the generator automatically advances to question 2, then question 3, and so on. When all questions in a language are done the quiz returns to the language-selection menu. Add as many question sub-folders as you like — the numbering controls the order.

Icon mapping

Image files (.jpg, .jpeg, .png) placed anywhere in your folder structure are automatically matched to tracks as icons. The generator applies these rules in order — the first match wins:

  • Same folder, match by filename — an image whose base name (without extension) exactly matches a track's filename. e.g. Intro.jpg → Intro.mp3
  • Same folder, match by prefix number (special tracks only) — an image whose name is a plain number that matches the #NN prefix. e.g. #01.jpg → #01 Bird.mp3
  • Parent (or ancestor) folder, match by folder name — an image next to a sub-folder whose name matches the folder becomes the icon for every track inside it. e.g. Treasure Island/ is a sub-folder with Treasure Island.jpg in the parent — all tracks inside get that icon.
  • Parent (or ancestor) folder, match by prefix number — same as above, but using the #NN prefix number on the folder name. e.g. #01 Treasure Island/ is a sub-folder with #01.jpg in the parent — all tracks inside get that icon.
#00 icon.jpg #00 Intro.mp3 ← icon: #00 icon.jpg #01 Story.mp3 ← icon: #01.jpg #01.jpg #01 Story/ Intro.jpg Intro.mp3 ← icon: #01 Story/Intro.jpg Track 1.mp3 ← icon: #01.jpg (from parent) Track 2.mp3 ← icon: #01.jpg (from parent)
